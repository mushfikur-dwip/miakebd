# suglow.com robots.txt
#
# Served from the web root so it bypasses Laravel's catch-all route.
#
# robots.txt groups are EXCLUSIVE: a bot that matches its own User-agent block
# ignores the "*" block entirely. So every named block below must repeat the
# full private-path list — a named block that omits one is a hole, not an
# inheritance. (The old Bingbot block did exactly that, leaving /login,
# /register, /password/ and /account/ crawlable by Bing alone.)
#
# The named AI blocks are deliberate opt-ins. Answer engines — ChatGPT Search,
# Perplexity, Claude, Gemini, Apple Intelligence, Google AI Overviews — cite the
# pages they are allowed to read, so welcoming their crawlers is how a product
# page becomes the source an AI answer links to. Training-only agents
# (Google-Extended, Applebot-Extended, GPTBot) are allowed too: for a retailer,
# being in the model's memory of "authentic cosmetics in Bangladesh" is upside.

User-agent: *
Disallow: /admin/
Disallow: /api/
Disallow: /login
Disallow: /register
Disallow: /password/
Disallow: /cart
Disallow: /checkout
Disallow: /account/
Disallow: /*?sort=
Disallow: /*?filter=
Allow: /
